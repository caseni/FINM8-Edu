# M8 EDU Profile Guidance Contract

## Separation of concepts

The learner profile and presentation mode solve different problems:

- learning stage describes the learner's self-reported starting context;
- goals describe why the learner is studying;
- Normal/Pro controls explanation density and terminology.

Changing one never silently changes another.

## Personalization boundary

Wave 1 keeps its canonical foundation order for every learner. Profile data may
adapt:

- the short reason why a lesson matters;
- the learning-process hint shown beside the mission;
- future review and optional-path recommendations.

Profile data does not skip prerequisites, unlock challenges, change quiz truth,
or hide safety content.

## Transparency

The home screen shows the active profile, selected goals, and an edit action.
It also states that the foundation path order is fixed while guidance adapts.
Personalized text must be deterministic and reviewable; it is not generated as
unbounded financial advice.
